# ⚾ KBO 프로야구 인기 좌석 실시간 선착순 예매 시스템

## 1. 서비스 소개
- **기획 배경:** KBO 포스트시즌 및 인기 경기 티켓 오픈 정각에 접속자가 순간적으로 집중되는 트래픽 폭주 상황을 가정한 실시간 선착순 좌석 예매 웹서비스입니다.
- **대상 사용자:** 프로야구 경기 좌석 예매를 원하는 야구 팬 및 좌석 시야 정보를 등록·관리하는 운영자
- **핵심 사용자 기능 (3가지):**[cite: 6, 9, 11]
  1. **경기 및 좌석 구역 등록 (AWS S3 연동):** 경기/구역명, 예매 가능 좌석, 좌석 시야 이미지를 업로드하면 AWS S3 버킷에 저장하고 목록에 렌더링합니다.[cite: 8, 9]
  2. **실시간 선착순 좌석 예매:** 팬 ID(연락처)와 이름을 입력해 원하는 좌석을 예매하며, Redis 원자적 연산(`SET NX`)을 통해 동시 요청 시 선착순 1명만 확정 처리합니다.[cite: 9]
  3. **내 예매 내역 조회 및 취소:** 팬 ID로 본인 예매 내역을 조회하고 취소할 수 있으며, 취소 즉시 해당 좌석이 예매 가능 상태로 복구됩니다.[cite: 9]
